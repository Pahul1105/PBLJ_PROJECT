# Step 3: Model Layer — Student.java

## 📌 What This Step Does

The **Model Layer** contains the `Student` class — a plain Java object (POJO) that represents
a single student record from the database. This class uses **Encapsulation** (a core OOP concept)
by keeping fields private and providing public getters and setters.

## 🔗 How It Connects to Other Parts

- **StudentDAO.java** (Step 5) creates `Student` objects when reading data from the database
- **Servlets** (Step 6) pass `Student` objects to JSP pages for display
- **JSP Pages** (Step 7) access student data using getter methods via EL expressions

### Connection Flow:
```
Database → StudentDAO reads rows → Creates Student objects → Servlet sends to JSP → JSP displays
```

## 💻 Code Explained

```java
package com.studentproject.model;

/**
 * Student Model Class (POJO - Plain Old Java Object)
 * 
 * This class represents a student entity in the system.
 * It maps directly to the 'students' table in the database.
 * 
 * OOP Concepts Used:
 * - Encapsulation: Private fields with public getters/setters
 * - Constructors: Default + Parameterized constructors
 */
public class Student {

    // ===== PRIVATE FIELDS (Encapsulation) =====
    // These fields match the columns in the 'students' database table
    private int id;         // Maps to: id INT PRIMARY KEY AUTO_INCREMENT
    private String name;    // Maps to: name VARCHAR(100) NOT NULL
    private double marks;   // Maps to: marks DOUBLE NOT NULL

    // ===== CONSTRUCTORS =====

    /**
     * Default Constructor (no arguments)
     * Required by many frameworks and for creating empty Student objects
     */
    public Student() {
    }

    /**
     * Parameterized Constructor (with all fields)
     * Used when reading a complete student record from the database
     * 
     * @param id    the student's unique ID
     * @param name  the student's name
     * @param marks the student's marks
     */
    public Student(int id, String name, double marks) {
        this.id = id;
        this.name = name;
        this.marks = marks;
    }

    /**
     * Parameterized Constructor (without id)
     * Used when adding a new student — id is auto-generated by MySQL
     * 
     * @param name  the student's name
     * @param marks the student's marks
     */
    public Student(String name, double marks) {
        this.name = name;
        this.marks = marks;
    }

    // ===== GETTERS AND SETTERS =====

    public int getId() {
        return id;
    }

    public void setId(int id) {
        this.id = id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public double getMarks() {
        return marks;
    }

    public void setMarks(double marks) {
        this.marks = marks;
    }

    // ===== toString METHOD =====
    /**
     * Returns a string representation of the Student object.
     * Useful for debugging and logging.
     */
    @Override
    public String toString() {
        return "Student [id=" + id + ", name=" + name + ", marks=" + marks + "]";
    }
}
```

## 📝 Key OOP Concepts Demonstrated

### 1. Encapsulation
- Fields (`id`, `name`, `marks`) are declared **private**
- Access is controlled through **public getter/setter methods**
- This protects data from unauthorized direct access

### 2. Constructors
- **Default constructor**: `Student()` — creates empty object
- **Parameterized constructors**: Initialize object with values
- **Constructor overloading**: Multiple constructors with different parameters

### 3. toString() Override
- Overrides the method from `Object` class (parent of all Java classes)
- Demonstrates **method overriding** (polymorphism concept)
